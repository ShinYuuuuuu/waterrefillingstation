# Planning Rules

## When to Plan

Create an implementation plan for large features and complex tasks.

Skip planning for trivial, straightforward tasks.

If the requested task is estimated to take less than 5 minutes, skip planning and implement directly.

## Implementation Plan

For tasks that require planning, define:

- The implementation steps in order.
- The files that will be affected.
- The risks and potential issues.
- The dependencies between steps.

## Identify Affected Files

- Map out which files need changes.
- Understand how changes propagate through the codebase.
- Check for related files that may need updates.

## Identify Risks

- Note potential breaking changes.
- Identify areas where the fix could cause regressions.
- Consider edge cases and failure modes.

## Identify Dependencies

- Note any external systems, APIs, or services involved.
- Identify prerequisite changes that must happen first.
- Check for third-party constraints.
