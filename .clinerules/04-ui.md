# Frontend Standards

## Responsive Layouts

- Use responsive design for all user interfaces.
- Ensure layouts work across screen sizes.
- Use relative units and flexible grids.

## Accessibility

- Follow WCAG guidelines.
- Use semantic elements for structure.
- Ensure keyboard navigation works.
- Provide meaningful alt text for images.
- Use sufficient color contrast.

## Semantic HTML

- Use appropriate HTML elements for their intended purpose.
- Avoid generic containers when semantic elements exist.
- Use headings in logical order.

## Reusable Components

- Build components that can be reused across the application.
- Keep components focused on a single responsibility.
- Accept configuration through props or parameters.

## Tailwind Best Practices

- Prefer Tailwind utility classes over custom CSS.
- Use design tokens and theme values consistently.
- Avoid arbitrary values when theme tokens exist.
- Keep responsive variants consistent.

## React Best Practices

- Use functional components with hooks.
- Keep components pure and predictable.
- Manage state at the appropriate level.
- Use keys correctly in lists.
- Avoid unnecessary re-renders.

## Modern UI Consistency

- Follow the existing design patterns in the project.
- Use consistent spacing, typography, and colors.
- Maintain a uniform visual language.

## Important

Never redesign existing UI unless explicitly requested.
