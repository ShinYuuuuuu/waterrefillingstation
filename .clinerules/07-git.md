# Git Workflow Rules

## Commit Standards

- Make small, focused commits.
- Each commit should represent a single logical change.
- Write clear, descriptive commit messages.
- Keep commits atomic.

## File Limit

If a task requires modifying more than 10 files, pause and explain why before continuing.

## Best Practices

- Do not mix unrelated changes in a single commit.
- Do not include generated or ignored files in commits.
- Keep the history clean and readable.
- Prefer a series of small commits over one large commit.
